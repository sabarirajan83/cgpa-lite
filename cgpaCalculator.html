Degree classification (Clause 14.2)

🏅 First Class with Distinction — CGPA ≥ 8.50, all courses in first attempt, no prevention from ESE
🎓 First Class — CGPA ≥ 6.50
📄 Second Class — qualified for degree but not in First or Distinction

Passing requirements (Clause 11.1)

• Minimum 50% total marks (Continuous Assessment + End Semester Examination)
• Minimum 45% in End Semester Exam individually (theory & lab)
• EEC courses (except project work): minimum 50% via continuous assessment only
• Percentage of marks = CGPA × 10
