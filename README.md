# Anna University CGPA Calculator

A simple and lightweight GPA and CGPA calculator built for Anna University (Regulation 2023 CBCS).

👉 **Live Calculator:** [Click here to open the calculator](https://sabarirajan83.github.io/cgpa-lite/)

---

## What It Does

- Calculates single semester **GPA**
- Calculates cumulative **CGPA** across multiple semesters
- Displays equivalent percentage (`CGPA × 10`)

---

## How to Use

1. **Semester GPA:** Enter your course credit units, select your grades, and click **Calculate GPA**.
2. **Multi-Semester CGPA:** Add semesters, fill in your grades, and click **Calculate CGPA**.
3. **Reference:** Check the Grade Reference tab for official marks ranges and grade points.

---

## Run Locally

No installations or build tools needed.

1. Download or clone this repository.
2. Double-click `index.html` to open it in any web browser.
